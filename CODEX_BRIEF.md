# Codex Project Brief

Implement a parametric FDM storage-case project called **Vault Lite**.

Read:
1. `README.md`
2. `docs/specs.md`
3. `docs/project-plan.md`
4. all files in `reference/`

Rules:
- Separate KNOWN, INFERRED, and TESTED dimensions.
- Never invent unknown magnet dimensions.
- Keep geometry parametric and source-controlled.
- Prefer OpenSCAD initially unless another scriptable CAD workflow clearly improves the result.
- Design for PETG on a Bambu Lab X1 Carbon.
- First printable artifact is a calibration coupon, not a full case.
- Do not copy third-party logos or branding.
- Commercial products are functional/layout references, not a request for a trademark-identical replica.
- Mini and Mega should share reusable CAD primitives and visual language.
- Document uncertainty for every photo-derived measurement.

Start by:
1. creating the CAD skeleton and central parameter file;
2. documenting KNOWN / INFERRED / TBD dimensions;
3. analyzing the Mini reference;
4. producing a first calibration-coupon source file that can be completed once magnet dimensions are supplied.

Do not proceed to a production-ready case while required physical dimensions remain unresolved.
